# Changelog

All notable changes to this project will be documented in this file.

## [e6c6c2e] - 2024-01-27
### Feedback page modified and made more visually attractive

Enhanced the feedback page with significant visual improvements to create a more polished and engaging user experience:

- **Background Enhancement**: Added a background image (feedback_bg.jpg) with cover sizing and center positioning to create visual depth
- **Typography**: Updated the page heading to uppercase ("RATE OUR SERVICE") and applied Georgia serif font styling
- **Button Redesign**: Replaced old button styles with modern gradient buttons featuring radial-gradient backgrounds (blue to cyan), improved shadows, and smooth hover/active state transitions with translateY animations
- **Form Styling**: Updated textarea borders to 1.5px blue (#5468ff) with aliceblue background color for better contrast and visual hierarchy
- **Container Design**: Modified glassmorphism container background to blue-tinted rgba(46, 123, 225, 0.1) for better cohesion with new color scheme
- **Star Rating**: Changed star color from gold (#FFD700) to beige (#eae3be) for softer appearance
- **Placeholder Text**: Updated textarea placeholder to "Remember to be nice please!" for better user guidance
- **Spacing & Layout**: Enhanced spacing between label and textarea with br tags, improved overall form element alignment

These changes significantly improve the visual appeal while maintaining accessibility and usability standards.
